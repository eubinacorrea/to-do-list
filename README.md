# 📝 **TODO List - Practical Project**

A simple, functional task manager to learn JavaScript, HTML, and CSS.

## 🚀 **How to Use**

1. Open the `todo-list.html` file in a web browser
2. Type a task in the text field
3. Click "Add" or press **Enter**
4. Use the buttons to **mark as done** or **delete**

## 📚 **What You'll Learn**

✅ **DOM Manipulation** - Get HTML elements with `getElementById()`  
✅ **Events** - Respond to clicks and keypresses with `addEventListener()`  
✅ **Arrays and Objects** - Store data in structures  
✅ **Functions** - Organize code into reusable blocks  
✅ **Logic** - Create, update, and delete data  
✅ **Dynamic CSS Classes** - Change styles with JavaScript  

## 🛠️ **Code Structure**
HTML         → Structure (input, button, list)
CSS          → Styling (colors, layout, animations)
JavaScript   → Logic (add, delete, update)

## 💪 **Challenges to Practice**

Try modifying the code:

1. **Task Counter** - Display how many tasks are pending
2. **Save in Browser** - Use `localStorage` to keep tasks when you reload
3. **Filter Tasks** - Buttons to view "All", "Completed", or "Pending"
4. **Edit Task** - Click to edit an existing task

# 📝 TODO List - Projeto Prático
 
Um gerenciador de tarefas simples, funcional para aprender JavaScript, HTML e CSS.
 
## 🚀 Como Usar
 
1. Abra o arquivo `todo-list.html` em um navegador
2. Digite uma tarefa no campo de texto
3. Clique em "Adicionar" ou pressione **Enter**
4. Use os botões para **marcar como pronto** ou **deletar**
## 📚 O que Você Aprende
 
✅ **Manipulação do DOM** - Pegar elementos do HTML com `getElementById()`  
✅ **Eventos** - Responder a cliques e teclas com `addEventListener()`  
✅ **Arrays e Objetos** - Guardar dados em estruturas  
✅ **Funções** - Organizar código em blocos reutilizáveis  
✅ **Lógica** - Criar, atualizar e deletar dados  
✅ **Classes CSS Dinâmicas** - Mudar estilos com JavaScript  
 
## 🛠️ Estrutura do Código
 
```
HTML         → Estrutura (input, botão, lista)
CSS          → Estilo (cores, layout, animações)
JavaScript   → Lógica (adicionar, deletar, atualizar)
```
 
## 💪 Desafios para Praticar
 
Tenta modificar o código:
 
1. **Contador de Tarefas** - Mostre quantas tarefas faltam
2. **Salvar no Navegador** - Use `localStorage` para manter as tarefas quando recarrega
3. **Filtrar Tarefas** - Botões para ver "Todas", "Completas" ou "Pendentes"
4. **Editar Tarefa** - Clique para editar uma tarefa existente
